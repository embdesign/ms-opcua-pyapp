Coverage limitations

  • Functional and interoperability checks - not official OPC UA certification.
  • The suite exercises one session, one browse root and one variable; it does not verify the whole address space or every DataType.
  • Writes and method calls are off by default and, when enabled, run only against the single targets the operator configured and confirmed. No writable node is discovered or written automatically.
  • Subscription checks record the initial value plus any changes within the observation window; a value that does not change is reported as passed with an explicit note, not as a failure.
  • Latency figures are client-side round-trip measurements of a few reads; they are not a performance benchmark and do not include server-internal processing time.
  • Access-denied nodes, timeouts and unsupported DataTypes are reported as limitations, not silently ignored.
